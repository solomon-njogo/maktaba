# The light reference system is the only theme

The Library home is built from a light, frosted reference, and the header and tab bar are shared by every shelf. A light home and a dark rest of the app would switch palette on every navigation.

We replace the dark-first, near-monochrome tokens with that reference system: a warm light canvas, frosted cards, soft shadow, pill controls, and dark summary panels. It is the only theme. Status badge colors stay, so Reading, Done, TBR, and Borrowed remain distinguishable. Other shelves keep their list layouts.

## Considered options

- Restyle the home inside the existing near-black tokens. Rejected: the reference materials are the design, and the written dark-first palette now describes the system we left.
